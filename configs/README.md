# Configuration

`manuscript_display_crosswalk.json` defines the saved manuscript's Figures 1–5 and S1–S14, their captions, pinned PNGs and native source IDs. `manuscript_inventory.json` records the stable native replay IDs and the donor readiness gates. `supplementary_table_crosswalk.json` identifies the current supplementary table exports.

`figure_02.yaml` retains the source-traced K=300 clustering contract. `figure_s03.yaml` preserves the legacy diagnostics configuration for native Figure S4, displayed as Figure S6 in the current manuscript. `table_s01.json` renders Table S2A. `table_s02.json` preserves the earlier annotation-metrics table setup. Input filenames retain their original identifiers.

`cell_type_colors.csv` is the shared cell-type palette. `duke_record_565_manifest.json` pins historical Figure 1/S1/S2 input identities. Do not add credentials or machine-specific paths.
