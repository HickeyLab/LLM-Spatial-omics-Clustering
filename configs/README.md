# Configuration

`manuscript_inventory.json` defines current Figures 1–5 and S1–S10, panel IDs, artwork checksums and table labels. `supplementary_table_crosswalk.json` maps unchanged companion filenames to current S1–S8 headings.

`figure_02.yaml` retains the source-traced K=300 clustering contract. `figure_s03.yaml` is the compatible legacy configuration for current Figure S4 diagnostics. Its archived FlowSOM sensitivity panel is not equivalent to the final FlowSOM method. `table_s01.json` now renders current Table S2A, and `table_s02.json` renders current Table S3. Input filenames retain their original identifiers.

`cell_type_colors.csv` is the shared cell-type palette. `duke_record_565_manifest.json` pins historical Figure 1/S1/S2 input identities. Do not add credentials or machine-specific paths.
