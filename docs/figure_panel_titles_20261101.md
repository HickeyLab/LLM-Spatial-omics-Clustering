Ten of the 17 artwork files change in this pass. All figures were reviewed
against this rule. The seven remaining files already use functional labels.
Optional numerical replay plots follow the same policy, including bare A–D
letters for S9. The canonical native renderer, publication exports,
manuscript images, notebook previews and manifests are synchronized.

No frozen numerical input, model output, fit, cell coordinate, scale or
scientific value is changed. The source illustrations and workflow labels
are preserved. Prior verification receipts describe earlier snapshots.

The verification receipt checks changed text regions in the final DOCX
against the new native files, so a largely white background cannot make an
old image pass as its replacement. Existing manuscript image crop rectangles
are preserved and their cropped native strips contain only white pixels.
Native nontext vector geometry and embedded image layers are unchanged.
