# Current marker-expression display definitions

Figure 2I and current Figure S4A use fractions of stored processed marker values strictly greater than zero. Color is the all-cell group mean, min–max scaled separately per marker across displayed groups. These fractions are not validated biological marker positivity. Figure 2I uses CD8+ T groups selected by modal LLM annotation. S4A uses original reference classes with Noise excluded.

See [marker_expression_thresholds.md](marker_expression_thresholds.md) for provenance. Current captions are frozen as read in `data/frozen/manuscript_replay/captions.json`. The earlier proposed wording is archived. This document makes no manuscript edits.
