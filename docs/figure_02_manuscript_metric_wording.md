# Figure 2 metric wording

Source-verified wording proposed in the Google Docs manuscript as suggestions.

## Section 2.9

To evaluate the fixed clustering partitions, we assigned each cluster its most frequent harmonized reference label globally across the eight regions and calculated per-cell-type precision, recall and F1. Figure 2F reports F1, the harmonic mean of precision and recall. Figure 2H reports recall, defined as true-positive cells divided by all cells of that reference type. These heatmaps exclude Noise and retain their historical 20-class mapping, including Paneth to Goblet. This differs from the annotation-scoring vocabulary in Section 2.5, which maps Paneth to Neuroendocrine and retains Noise. Cluster purity, the sum of the largest reference-class count in each cluster divided by the total cell count, is a separate metric and is not the quantity plotted in Figure 2G.

Figures 2E and 2G instead show post-hoc selected reference agreement. For each cell and each method-model pair, a match is counted if either the stored Phase-7 prediction or that method-model prediction equals the harmonized reference label. Within each region, the plotted value is the arithmetic mean of this match fraction across four models. The calculation includes all 220,082 cells and the historical 21-label scoring vocabulary, including Noise. Both panels display the same 32 method-by-region values with different y-axis limits. Boxes show the median, interquartile range and default 1.5-interquartile-range whiskers, with all eight regional observations shown for each method. Because the score selects matches using the reference labels on the evaluated cells, it is a retrospective, selection-biased summary of clustering and annotation. It is not regional cell-count-weighted F1, regional cluster purity, independent validation, deployable annotation performance or direct agreement from one fixed prediction map.

## Section 3.2

Cell-type F1 and recall after global reference-majority assignment varied across methods and reference populations (Figures 2F and 2H). Figures 2E and 2G show the same regional post-hoc selected reference agreement, averaged over four models, on different y-axis scales. These panels combine clustering and annotation and use reference labels to select matches on the evaluated cells. They therefore do not isolate clustering performance and should not be read as regional F1, cluster purity or an independently validated annotation benchmark. The eight regional observations describe variation within one donor.

## Figure 2 caption

Figure 2. Benchmarking unsupervised cell-type clustering methods. (A) Workflow from CODEX images and cell-level features through clustering, visualization, preliminary majority-label assignment, and evaluation against reference cell types. (B) Reference cell counts by cell type in the healthy human intestine dataset. (C) Reference spatial cell-type map for one tissue region. (D) UMAP embeddings colored by reference or clustering-derived cell-type assignments for Leiden, FlowSOM, SpatialSort, and PIXIE. Boxed regions are enlarged above [33]. (E) Post-hoc selected reference agreement by clustering method across eight tissue regions, averaged across four models. (F) F1 scores by cell type and clustering method, with reference cell counts at right. (G) The same post-hoc selected reference agreement values as (E), displayed with different y-axis limits. (H) Cell-type-specific recall by clustering method, with reference cell counts at right. (I) Protein marker expression profiles grouped by the modal cell labels from the historical LLM benchmark for each clustering partition. (J) Reference and method-derived spatial cell-type maps for representative regions with low or high reference agreement for the combined clustering-and-annotation workflow. Cell-type colors in (C), (D), and (J) correspond to the legend in Figure 2B. For (E) and (G), a cell counts as a match if either the stored Phase-7 prediction or the individual method-model prediction matches its harmonized reference label. These panels include Noise and use reference labels to select matches on the same cells. They show a selection-biased retrospective summary, not F1, cluster purity or direct agreement from one fixed prediction map (Section 2.9). Panels F and H use their historical non-Noise 20-class majority-mapping evaluation (Section 2.9). Panels I–J use the most frequent predicted label across GPT-5.6-Sol, Claude Opus 5, Gemini 3.1 Pro Preview and DeepSeek V4 Pro in the historical benchmark (Sections 2.12–2.13 and 3.3), with ties resolved in that order. They combine clustering and annotation rather than isolate clustering alone.
