# Versioned manuscript tables

This directory stores the small, authoritative tabular inputs needed to
rebuild manuscript tables from a clean clone. These files are versioned inputs,
not generated output.

`supplementary_table_s02_marker_summary_optimization.csv` records the complete
fine-grid ranges and the selected marker-summary parameters for Table S2. Its
SHA-256 digest is
`e91af5dfc7ef27687aa8b07acbc74b86f9c2f119228dc1d2db20034f5ec671f4`.

Generated Table S2 PNG and PDF files are written to
`outputs/source_rebuilt/table_s02/` and remain untracked.
