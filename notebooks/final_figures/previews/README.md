# Publication previews

These PNG files are byte-for-byte copies of validated source-traced
publication outputs. They are committed so reviewers can see each result on
GitHub without downloading the full data or rerunning the analysis.

They are not notebook execution state and are never used as reconstruction
inputs. Regeneration is controlled by the code and input contracts in the
parent notebooks.
